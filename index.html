Descripción del proyecto

Este sitio web ha sido desarrollado como parte de la materia de Programación Web y Multimedia. El proyecto tiene como objetivo aplicar los conocimientos adquiridos sobre HTML y la estructura básica de un sitio web utilizando etiquetas semánticas.

Objetivo del sitio web

El objetivo de este sitio es presentar un ejemplo sencillo de una página web estructurada, donde se pueda navegar entre diferentes secciones como la página principal, los integrantes del grupo y el repositorio del proyecto.

Información de la materia

La materia de Programación Web y Multimedia enseña los fundamentos del desarrollo web, incluyendo el uso de HTML, CSS y herramientas de colaboración como Git y GitHub.

Introducción al proyecto

Este proyecto consiste en la creación de un sitio web básico donde los estudiantes puedan aplicar buenas prácticas de estructura y organización del contenido utilizando HTML.
